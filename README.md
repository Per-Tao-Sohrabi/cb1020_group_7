# Angiogenesis in The TME
This projects consittutes an abstract agent based 2 dimensional model of the angiogenesis phenomena observed for tumor cells, in the proximity of blood vessles. 

## Design
An application of object oriented programming is agent based modeling. This programme consists of a number of modules that enable the simulation to run locally and behave as intended: five agent classes, and a MainModel class. 


The five agent classes shares a position attribute as well as various specific attributes to enable cell-like behaviours.
